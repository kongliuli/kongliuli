## 精选项目

### [NetPulse](https://github.com/kongliuli/NetPulse)

Windows 原生网络流量监控与代理诊断工具，延续 NetStrata 的网络健康监控探索，关注日常网络状态与问题定位。

### [DataForge.Core](https://github.com/kongliuli/DataForge.Core)

**CSV → 转换与校验 → JSON** 的 .NET 数据处理管道，让导入、清洗和导出流程更容易复用。

### [AstrLink](https://github.com/kongliuli/AstrLink)

面向 AI Agent 的本地 AI 网关，统一模型接入，关注端侧隐私与本地运行。
